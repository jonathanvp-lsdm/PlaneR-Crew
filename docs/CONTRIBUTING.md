# Contribuer à Plane'R Crew

Merci de votre intérêt pour Plane'R Crew.

Ce projet est actuellement un projet privé développé pour l'association **Les Sonorités de Montcul (LSDM)**.

---

# Concepteur du projet

Le concept, les besoins fonctionnels, l'organisation métier et la vision du logiciel ont été imaginés et définis par :

**Jonathan Van Passenhove**

Président de l'association Les Sonorités de Montcul.

---

# Objectif

Toute contribution doit respecter la Constitution du projet disponible dans :

docs/CONSTITUTION_PLANE_R_CREW.md

Plane'R Crew est exclusivement dédié à la gestion des bénévoles du Plane'R Fest.

---

# Principes de développement

Toute contribution doit respecter :

- l'architecture du projet
- les normes de développement
- la modularité
- les composants Core
- le respect du RGPD
- la simplicité d'utilisation

---

# Workflow

Chaque évolution suit les étapes suivantes :

1. Conception
2. Développement
3. Tests
4. Validation
5. Documentation
6. Déploiement

---

# Documentation

Avant toute contribution, lire :

- README.md
- docs/CONSTITUTION_PLANE_R_CREW.md
- docs/ARCHITECTURE.md
- docs/NORMES_DEVELOPPEMENT.md

---

# Développement

Les nouvelles fonctionnalités doivent répondre à une seule question :

> Cette fonctionnalité aide-t-elle les responsables bénévoles ?

Si la réponse est NON, elle n'a probablement pas sa place dans Plane'R Crew.

---

Merci de contribuer à faire de Plane'R Crew un logiciel simple, fiable et durable.
